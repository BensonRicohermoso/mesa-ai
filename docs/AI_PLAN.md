# MESA-AI: Gemini & Owner AI Implementation Plan

**Branch:** `feature/dev2-ai`  
**Owner:** Dev 2 (`server/src/modules/ai`, `client/src/features/owner`)  
**Status:** Implemented on `feature/dev2-ai` (Preview mode verified; Live analytics pending Dev 1)  

This document defines the unified plan for all Dev 2 AI features (Gemini integration, daily briefing & anomaly alerts, forecast & recommendations, and owner-only AI Q&A), along with architectural safeguards and predicted bugs to prevent during implementation.

---

## 1. Core Rules & Constraints

1. **Server-only API key:** `GEMINI_API_KEY` stays on the server via `env.GEMINI_API_KEY` in `server/src/config/server-config.js` and is never exposed to the client.
2. **Verified numbers only:** The backend computes every KPI, delta, anomaly flag, and baseline forecast. Gemini only explains verified results.
3. **Facts vs. Interpretation:** Every AI response and UI card must clearly separate **Verified Data** from **AI Interpretation**.
4. **Terminology:** Use **gross profit** and **gross margin** only. Never use "net profit" (rent, labor, and utilities are not tracked).
5. **Read-only AI:** AI recommendations never automatically modify menu items, prices, or orders.
6. **Admin-only access:** All `/api/ai/*` endpoints require `authenticate` and `requireRoles("admin")`.

## 2. Backend Plan (`server/src/modules/ai/`)

### 2.1 File Structure

- `server/src/modules/ai/ai.routes.js` — Express router mounted at `/api/ai` in `server/src/index.js`, protected by `authenticate`, `requireRoles("admin")`, and a per-staff `express-rate-limit` middleware (in that order, keyed by `req.auth.staff.id`).
- `server/src/modules/ai/ai.controller.js` — Request validation, error forwarding to `errorHandler`, and HTTP response formatting.
- `server/src/modules/ai/ai.service.js` — Orchestration, analytics snapshot adapter, bounded TTL + in-flight deduplication cache, anomaly threshold checks, prompt building, and deterministic fallback generator.
- `server/src/modules/ai/gemini.client.js` — Thin Gemini API client using `env.GEMINI_API_KEY`, configurable `env.GEMINI_MODEL` (default `gemini-2.5-flash`), `AbortSignal.timeout(12000)`, and JSON fence stripping.
- `server/tests/ai.test.js` — Automated tests (run without requiring a live `GEMINI_API_KEY` via mocked client) covering auth/RBAC, validation, fallback behavior, Q&A bounds, and cache/rate-limit behavior.

### 2.2 Analytics Data Adapter (Unblocks Dev 2 from Dev 1)

`server/src/modules/analytics/analytics.service.js` is currently a stub pending Dev 1. To avoid blocking `feature/dev2-ai`:

- `ai.service.js` will call a `getVerifiedMetricsSnapshot({ from, to, tz, compare, categoryId, paymentMethod, sourceMode })` adapter.
- When `sourceMode === "preview"` (or when live analytics is not yet wired), the adapter uses deterministic preview metrics matching `client/src/features/owner/analyticsPreviewData.js`.
- When `sourceMode === "live"`, it calls Dev 1's `analytics.service.js` functions once implemented (and returns a clear `501` / fallback notice if live analytics is not yet available).

### 2.3 API Endpoints (`/api/ai/*`)

#### `GET /api/ai/status`
Returns AI readiness without exposing secrets:
- `configured`: boolean (`Boolean(env.GEMINI_API_KEY)`)
- `model`: configured model name
- `mode`: `"gemini"` | `"fallback"`
- `cacheEntries`: number of active cached entries

#### `POST /api/ai/briefing`
Request body:
```json
{
  "from": "2026-11-19",
  "to": "2026-11-25",
  "tz": "Asia/Manila",
  "compare": true,
  "categoryId": "all",
  "paymentMethod": "all",
  "sourceMode": "live",
  "forceRefresh": false
}
```
Response (`200`):
- `facts`: Verified KPIs, period-over-period deltas, and backend-computed anomaly flags (e.g., gross margin drop, cancellation spike, slow kitchen prep).
- `interpretation`: `{ summary, alerts[], watchItems[] }` generated by Gemini (or deterministic fallback).
- `meta`: `{ source: "gemini" | "fallback", model, generatedAt, cached, sourceMode }`.

#### `POST /api/ai/forecast`
Request body:
```json
{
  "from": "2026-11-19",
  "to": "2026-11-25",
  "tz": "Asia/Manila",
  "categoryId": "all",
  "paymentMethod": "all",
  "horizonDays": 7,
  "sourceMode": "live",
  "forceRefresh": false
}
```
Response (`200`):
- `facts`: Backend baseline projections (expected orders, gross sales, gross profit, peak hours) + menu engineering counts (Stars, Workhorses, Puzzles, Dogs).
- `interpretation`: `{ outlookSummary, peakHourAdvice, recommendations[] }` (promo/bundle/price ideas, read-only).
- `meta`: `{ source: "gemini" | "fallback", model, generatedAt, cached, sourceMode }`.

#### `POST /api/ai/qna`
Request body:
```json
{
  "question": "Why did gross margin change this week?",
  "history": [
    { "role": "user", "content": "..." },
    { "role": "assistant", "content": "..." }
  ],
  "from": "2026-11-19",
  "to": "2026-11-25",
  "tz": "Asia/Manila",
  "categoryId": "all",
  "paymentMethod": "all",
  "sourceMode": "live"
}
```
Guardrails:
- `question` trimmed, required, max 500 characters.
- `history` capped to the last 6 messages, each sanitized to `{ role: "user" | "assistant", content: string }` with max length.
Response (`200`):
- `answer`: Concise explanation grounded in verified metrics.
- `dataUsed`: Compact summary of the metrics snapshot used to answer.
- `meta`: `{ source: "gemini" | "fallback", model, generatedAt, sourceMode }`.

### 2.4 Caching & Deterministic Fallback

- **Bounded TTL + In-Flight Cache:** In-memory cache (5–10 min TTL, max 50 entries with oldest-entry eviction) keyed by `endpoint + from + to + tz + compare + categoryId + paymentMethod + horizonDays + sourceMode`, plus an in-flight Promise map so concurrent identical requests share one Gemini call. Supports `forceRefresh: true` when triggered by the toolbar's `Refresh` button.
- **Fallback:** If `GEMINI_API_KEY` is missing, quota returns `429`, the request times out, or JSON parsing fails, return `200` with `meta.source = "fallback"` and deterministic rule-based insights derived from `facts`.

## 4. Predicted Bugs & Mitigations

| Risk / Bug | Cause | Mitigation |
| --- | --- | --- |
| **LLM math hallucinations** | Model invents totals/percentages or says "net profit" | Compute all KPIs, deltas, and anomaly flags on the backend; pass pre-computed numbers only; enforce "gross profit / gross margin" in system prompt. |
| **Hanging requests / 504s** | Gemini API stalls or network drops | Wrap upstream calls in `AbortSignal.timeout(12000)` and fall back to deterministic insights on timeout/error. |
| **Quota `429` or missing key during demo** | `GEMINI_API_KEY` unset, expired, or rate-limited | Degrade gracefully to `meta.source = "fallback"` with a subtle UI badge instead of breaking the page. |
| **Token/context overflow in Q&A** | Unbounded `history` or raw order rows in prompt | Send aggregated summaries only and slice `history` to the last 6 turns on the server. |
| **Filter / Live vs. Preview mismatch** | User changes `categoryId`, `paymentMethod`, or `Live / Preview` while on AI tab | Include all active filter fields (`categoryId`, `paymentMethod`, `tz`, `sourceMode`) in AI request payloads and cache keys. |
| **Stale race conditions on tab/filter switch** | Slow Gemini response resolves after user switched dates or left the tab | Pass `AbortController.signal` from `useEffect` into `aiApi.js` and abort on cleanup. |
| **Shared-IP rate limit lockouts** | Multiple POS/owner sessions on restaurant Wi-Fi share one IP | Run `authenticate` before `express-rate-limit` and key the limiter by `req.auth.staff.id`, returning `errorHandler`-compatible JSON. |
| **Duplicate Gemini calls on double-click** | Two simultaneous requests miss the TTL cache | Deduplicate concurrent identical requests with an in-flight Promise map and support `forceRefresh` for manual Refresh. |
| **PIN-switch role leak** | Operator switches from `admin` to `cashier` via `PinPadModal` | Enforce `requireRoles("admin")` on all `/api/ai/*` routes and hide/guard the AI tab when `role !== "admin"`. |
| **Malformed JSON from LLM** | Model wraps JSON in markdown fences or truncates | Request `application/json` output from Gemini, strip markdown fences before `JSON.parse`, and fall back cleanly on parse error. |
